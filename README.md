# astrbot_plugin_proactive

让 AstrBot 里的角色**主动找你说话**，节奏按真人聊天规律来，而不是定时器。

## 它是怎么决定什么时候发

三个条件**同时**满足才发：

1. 距你上一条消息 ≥ `min_gap_after_user`（默认 45 分钟）——你正聊着它不打扰
2. 距上次主动 ≥ `min_gap_between`（默认 90 分钟）——不刷屏
3. 落在当天计划的时间点附近——计划按 `hour_weights` 生成，每天 `min_per_day`~`max_per_day` 次

默认权重来自一份真实聊天统计（146 天、656 次主动开场）：

```
0点 28  1点 35  2点 24  3点 20  4-6点 极低
10点 36  11点 47  12点 38  14点 44  15点 44
19点 39  20点 32
```

也就是说：白天和深夜会找你，凌晨四五点基本不打扰。

## 安装

1. 整个目录放进 `AstrBot/data/plugins/`
2. 重启 AstrBot
3. 配置里改 `scope`（默认只对私聊生效）

状态存在 `<插件>/data/state.json`，重启不丢。

## 配置

| 键 | 说明 |
|---|---|
| `scope` | `FriendMessage`（私聊）/ `GroupMessage`（群聊） |
| `min_gap_after_user` | 你多久没说话才主动（分钟） |
| `min_gap_between` | 两次主动最小间隔（分钟） |
| `min_per_day` / `max_per_day` | 每天主动次数区间 |
| `quiet_hours` | 不主动的小时列表 |
| `hour_weights` | 自定义每小时权重（留空用默认分布） |
| `openers_yaml` | 自定义开场白（YAML） |

### 自定义开场白

```yaml
morning: [早上好, 起床呢, 睡醒啦]
noon: [午好呢, 吃饭了没]
afternoon: [人呢, 嘿嘿, 下课了]
evening: [人呢, 回来啦]
night: [好困, 睡着了, 555]
any: [人呢, 嘿嘿, 哈哈哈]
```

## 命令

| 命令 | 作用 |
|---|---|
| `/主动 测试` | 立刻发一条，看看效果 |

## 注意

- 这个插件只做"什么时候开口"，发什么由开场白池决定。想让它接着上次的话题，需要另外接模型生成。
- 重启会重新生成当天计划。
- 如果 AstrBot 同时装了别的"主动消息"类插件，注意别重复发。
